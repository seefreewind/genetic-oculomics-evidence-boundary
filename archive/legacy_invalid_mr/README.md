# Legacy directional MR archive

This directory preserves the Phase 2 and Phase 2A.1 directional MR outputs that preceded Amendment 004.

These files are retained for provenance only. They are not valid inputs for scientific interpretation, manuscript claims, figures, tables, or the public Amendment 004 result set because the release-specific allele-frequency semantics of seven retinal vascular GWAS datasets could not be resolved authoritatively.

Amendment 003 is closed without corrected vascular MR. The controlling replacement analysis is Amendment 004, which restricts directional MR to the seven primary OCT traits with verified source frequency semantics and evaluates 112 directions across the same eight systemic diseases.
